## 🧾 Configuração do projeto

### 1. Clone o repositório

```bash
git clone https://github.com/AngeloResplandes/atividades-web2.git
cd atividades-web2/atividade4
```

### 2. Instale as dependências

```bash
npm install
```

### 3. Crie uma build do projeto

```bash
npm run build
```

### 4. Inicie o servidor

```bash
npm run preview
```
